- 已有独立 title、description、canonical、Open Graph、JSON-LD、`robots.txt` 和 `sitemap.xml`。
- 已安装百度统计，统计 ID 为 `30152a06c6c0e47f34a391e816362e80`。
- 已上线 `/blog/` 和两篇原创实践文章，并从首页、About、项目列表与案例页建立自然内链。
- Easy Resume 当前可访问地址为 `https://resume.esaylab.com/`；不要再使用无法完成 TLS 握手的 `resume.easylab.com`。
- 生产源站位于境外阿里云，正式站通过 Ubuntu Nginx 提供 HTTPS。

## 二、本周技术任务

### 1. 百度搜索资源平台

需要在已登录的百度搜索资源平台完成：

1. 验证 `https://summer2077.com/` 的站点归属。
2. 提交 `https://summer2077.com/sitemap.xml`。
3. 使用普通收录的 API 或手动方式提交当天新发布的 3 个 URL：
   - `https://summer2077.com/blog/`
   - `https://summer2077.com/blog/vibe-coding-from-idea-to-product/`
   - `https://summer2077.com/blog/ai-product-validation-checklist/`
4. 使用抓取诊断分别检查首页、博客列表和一篇文章：返回 200、正文完整、无超时。
5. 记录首次索引量、抓取频次、抓取异常和“流量与关键词”数据，作为后续对照基线。

普通收录只能缩短百度发现链接的时间，不保证索引或排名。官方说明：<https://ziyuan.baidu.com/linksubmit/index>。

### 2. 百度统计

在百度统计后台确认：

- 实时访客能收到首页和博客文章访问。
- 来源、受访页面和设备数据正常。
- 发布前后对比博客入口点击与文章访问，而不是把安装统计代码当作排名信号。

### 3. 国内网络性能

在决定 CDN 前，先记录真实基线：

- 使用移动、联通、电信网络分别打开首页和一篇博客文章。
- 记录是否打开成功、首屏体感、TTFB 和完整加载时间。
- 至少覆盖一个移动网络和一个固定宽带场景，避免用单一电脑结果代表全国用户。

生产 Nginx 应保持 gzip，并为版本化 CSS、JavaScript、WebP、PNG、SVG 配置长期缓存；HTML、`robots.txt` 和 `sitemap.xml` 使用短缓存。

## 三、CDN 决策

Cloudflare 免费版不等于中国大陆 CDN。Cloudflare 中国大陆节点属于 Enterprise 的单独 China Network 服务，并要求有效 ICP。官方说明：<https://developers.cloudflare.com/china-network/>。

执行规则：

1. 没有三网基线，不切换 DNS。
2. 只有实测证明免费代理改善成功率或延迟时才保留，否则回滚。
3. 源站证书有效时使用 `Full (strict)`，不使用普通 `Full` 或 `Flexible`。
4. 切换前记录 DNS、TTL、源站地址和回滚步骤。
5. CDN/WAF 不得拦截 Baiduspider、sitemap、robots 或普通用户。

### 后续选题原则

百度公开的内容判断维度是内容质量、权威性、浏览体验和时效性，而不是固定字数：

## 五、站外分发边界

百度知道、文库、经验、百家号和贴吧不是必须完成的技术 SEO 项目。只有能够给对应平台用户提供独立价值时才发布。

允许：

- 用真实身份回答与自身经验高度相关的问题。
- 把官网首发文章重新组织成适合平台读者的独立内容。
- 发布真正可复用的清单、教程或文档，并保持事实一致。

禁止：

- 自问自答、批量养号、伪装普通用户推荐自己的产品。
- 为“每周数量”拼凑低质回答、文库或帖子。
- 洗稿、关键词堆砌、购买垃圾外链、刷点击或刷排名。
- 在多个平台复制完全相同的正文，或用平台内容替代官网的长期内容资产。

第一阶段只选择一个站外渠道试跑。只有出现真实品牌搜索、引荐访问或有效咨询后，才扩大投入。

## 六、监测与复盘

### 每周

- 百度索引量和抓取异常。
- 新文章是否被发现、抓取和索引。
- 百度统计中的搜索来源、博客入口和文章访问。

### 每月

- 搜索资源平台的展现、点击、搜索词和落地页。
- 哪些文章带来项目页访问、邮件、GitHub 或社群行动。
- 内容是否仍然准确，是否需要补充证据、内链或更新时间。

不要因单周排名波动频繁修改 title。只有搜索意图不匹配、展现量足够但点击明显偏低，或正文已发生实质变化时才调整，并记录修改日期。

## 七、不能采用的说法

以下说法没有可靠官方依据，不得写入正式策略或作为决策前提：

- “未备案域名发生任何跳转都会被判作弊、整站降权”。正常 HTTP→HTTPS、www→主域跳转应保留，并提交最终 URL。
- “未备案站抓取频率固定为已备案站的五分之一”。
- “备案后收录量必然提高两倍”。
- “页脚备案号会让点击率提高 22%”。
- “文章必须 800–1500 字才有排名机会”。
- “安装百度统计会给搜索排名传递信任信号”。
- “Cloudflare 免费版可以保证国内 4G 三秒内打开”。

## 八、成功标准

- 所有 canonical 页面通过正式域名返回 200，未知路径返回定制 404。
- 百度可以抓取首页、博客列表和文章正文，无 robots 或 WAF 阻断。
- sitemap 只包含 canonical、允许索引且真实存在的页面。
- 新内容以真实索引、搜索展现、访问和后续行动评估，不以提交成功或第三方估算排名代替。
- 所有对外结论区分本地检查、浏览器运行、生产部署、搜索平台数据与仍待用户登录的外部步骤。
