> 制定日期:2026-08-09
> 适用对象:summer2077.com 个人品牌站(纯静态 HTML/CSS/JS)
> 核心认知:百度与 Google 算法体系、审核机制、生态规则完全不同,本策略以百度为中心制定。

## 二、第 0 步:合规基石(不可跳过)

### 2.1 ICP 备案 — 百度 SEO 的入场券
- **必须持有有效 ICP 备案**,并在页脚展示备案号(`京ICP备xxxxxxxx号` 格式)。
- 未备案的站点在百度会被直接过滤或降权,花再多钱做内容都没用。
- 备案周期:个人备案约 4–20 个工作日,建议尽快启动。
- 备案成功后:在首页 `<footer>` 加备案号 + 链接到 `beian.miit.gov.cn`。

### 2.2 服务器与中国大陆网络
- 百度明确偏好大陆机房(阿里云/腾讯云等)。若当前服务器在境外,收录和排名都会打折。
- 目标:全国主要城市 Ping < 100ms;建议接入大陆 CDN(阿里云 CDN / 腾讯云 CDN / EdgeOne)。
- 域名 DNS 使用国内解析服务(如阿里云 DNS、DNSPod),避免跨境解析延迟。

### 2.3 SSL 证书
- 必须全站 HTTPS。国内访问建议使用**国产 CA**(如 TrustAsia、沃通)或阿里云/腾讯云免费证书,部分国内环境对国外 CA 链兼容性更稳。

### 2.4 接入百度站长平台(ziyuan.baidu.com)— 本周必做
1. 注册并**验证站点所有权**(推荐 DNS 解析验证或 HTML 标签验证)。
2. **提交 sitemap**:`https://summer2077.com/sitemap.xml`。
3. 开启「普通收录」并关注**抓取诊断 / 抓取异常 / 收录量**数据。
4. 在「优化工具 → 快速收录」中按需提交重要页面(首页、about、3 个案例页)。
5. 配置「站点属性」:网站类型选"个人",完善行业分类,提高识别准确度。

### 2.5 安装百度统计(百度统计 tm.baidu.com)
- 全站引入百度统计代码,替代/并行于现有统计。
- 作用:① 看清百度来源流量;② 向百度传递站点活跃信号;③ 为后续"搜索词 → 落地页"优化提供数据。

## 三、技术 SEO(百度视角)

### 3.1 抓取友好(当前已是优势,保持)
- ✅ 正文 HTML 直出,不依赖 JS 渲染 —— 这是百度收录的**最大加分项**,重构时务必保持。
- ⚠️ 首页 Tab 面板(关于我/交流)默认 `hidden`。百度会抓取全部 HTML,但**首个 Tab 优先获得权重**,建议把「项目」放首位(当前已如此,正确)。

### 3.2 标题与描述(百度展示规范)
百度标题展示约 **30 个汉字**,描述约 **78 个汉字**。现有标题略超,按以下微调(只改必要处):

| 页面 | 建议 Title(≤30 字) | 说明 |
|------|--------------------|------|
| 首页 | `summer2077 - AI 产品专家、独立开发者与 AI 产品作品集` | 品牌词前置,去掉全角竖线(百度分词对 `｜` 处理不稳定) |
| /about/ | `关于 summer2077 - AI 产品专家与独立开发者` | 同上去竖线 |
| /projects/ | `项目作品 - summer2077 的 AI 产品与独立开发案例` | 保留 |
| easy-resume | `Easy Resume AI 简历大师 - 简历优化与 AI 修改工具` | 前 15 字带核心搜索词「AI 简历」 |
| tabifun | `TabiFun 旅行地图 - 从照片自动整理旅行路线` | 前 15 字带「旅行地图」 |
| ai-wardrobe | `AI 衣橱 - 拍照入库与每日穿搭推荐工具` | 前 15 字带「穿搭推荐」 |

> 注意:百度**清风算法**严打标题与内容不符。所有 title 必须真实对应正文,禁止蹭无关热词。

### 3.3 结构化数据(百度专属增强)
百度已支持 JSON-LD,在现有 schema 基础上补充:
- **站点 Logo 标记**(SiteNavigationElement 或 WebSite 的 logo 字段)→ 品牌词搜索有几率展示品牌形象。
- **面包屑标记**(BreadcrumbList):about/projects/案例页已有,首页可补,百度会用其生成面包屑展示。
- **Article/SoftwareApplication**:案例页已有,保留。
- 注意:百度对 `sameAs`(外链指向)较为敏感,当前 GitHub/抖音外链保留即可,勿堆砌。

### 3.4 移动端(百度 80%+ 流量来自移动)
- ✅ 响应式已达标。重点检查:
  - 移动端首屏加载 < 2s(当前静态 + WebP,基础良好)。
  - 无横向滚动、点击目标 ≥ 44px。
  - 微信/QQ 内打开体验正常(国内大量入口场景)。

### 3.5 速度优化(国内网络条件)
- 图片已是 WebP ✅;建议追加:HTTP/2、Gzip/Brotli(nginx 层)、静态资源长缓存。
- 若预算允许,接入大陆 CDN(见 2.2),移动端 LCP 目标 < 2.5s。

### 3.6 URL 与内链
- ✅ URL 结构清晰(`/projects/xxx/`),中文内链锚文本自然。
- 建议:三个案例页互相加上"相关项目"推荐链接,形成站内环,帮助权重在站内流动。

- 同义词自然覆盖:`手机`/`App`/`工具`、`简历`/`CV` 等。
- 保持简体中文,勿混繁体。

## 五、百度生态矩阵(百度排名的隐藏捷径)

百度对自家生态产品有明确加权,个人品牌站尤其受益。按优先级执行:

### 5.1 百家号(最高优先级,内容分发主阵地)
- 注册个人百家号,同步/改写博客文章。
- 百家号文章可进入百度搜索结果,并反哺站点品牌认知。
- 注意:百家号内容与站点内容避免完全重复(做差异化改写),防止被识别为采集。

### 5.2 百度知道(产品问答阵地)
- 围绕产品词提问自答(如「AI 简历工具哪个好用」「简历体检有用吗」),答案中自然提及产品名与价值,带官网链接(合规性:百度知道外链审核严,软性提及为主)。
- 积累回答者等级,提高可信度。

### 5.3 百度百科(品牌信任状)
- 为 **Easy Resume** 尝试创建词条(产品词条门槛低于个人词条);个人品牌词条需等影响力足够再申请。
- 词条需提供第三方可验证来源(GitHub、官网、媒体报道),禁止广告语气。

### 5.4 百度贴吧 / 百度文库 / 百度经验(辅助)
- 贴吧:在 `AI产品吧`、`独立开发吧` 等持续提供有价值内容,沉淀 ID 信誉。
- 文库:发布《AI 简历撰写指南》《Vibe Coding 入门》等文档,占"文档型搜索"位。
- 经验:发布「如何使用 Easy Resume 优化简历」步骤型内容。

### 5.5 搜狗 / 360 / 神马(交叉覆盖)
- 搜狗承接微信生态搜索;360 与神马是移动长尾补充。策略一致:内容为王,暂不单列投入。

## 九、红线与风险(触碰即死)

1. **无 ICP 备案运营** → 直接出局。
2. **刷点击/刷排名**(惊雷算法) → 整站降权。
3. **采集/拼接内容**(飓风算法) → 收录清零。
4. **标题党/内容不符**(清风算法) → 首页降权。
5. **B2B/黄页式堆砌**(细雨算法,主要影响企业站,个人站注意不堆砌产品词即可)。
6. 敏感话题内容 → 审核不通过,注意个人站话题边界。
